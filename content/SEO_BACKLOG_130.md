# BudgetLoom: 130 New SEO Article Opportunities

Source: GitHub `dvdphobia/budgetloom.xyz` on 2026-10-12.

Existing repository contains 23 hardcoded blog posts in `lib/posts.ts`. These 130 proposed new briefs are distinct from the existing slugs, producing a **153-post target** when fully implemented. Ideas are not verified keyword-volume estimates or ranking promises. Validate each topic with Search Console/SERP research; merge or retire overlapping intents. Publish only after quality review.

## Workflow per article

1. Check SERP intent, results, and whether an existing BudgetLoom page already satisfies it. One primary URL per search intent.
2. Create a brief with the exact reader question, audience, title, search intent, outline, illustration, example calculations, and a matched tool/printable.
3. Cite trustworthy primary sources where facts, fees, rates, rights, or methods require verification. Avoid jurisdiction-specific legal or tax advice without qualified review.
4. Produce a working original asset (example worksheet, calculator, table, downloadable PDF/CSV) and test all math. Word count follows the intent; do not pad to a fixed SEO word count.
5. Review by a named accountable author/editor, add honest author bio, methodology, created/updated dates, relevant links, and affiliate disclosures.
6. Add article -> pillar link, 2-4 relevant related internal links, and matching pillar/printable -> article links. Avoid keyword-stuffed exact-match anchors.
7. Test desktop/mobile, title/canonical/robots/schema, actual file download, performance, and ad density. Publish only with approval.
8. Recheck GSC after indexing and improve based on impressions, search queries, CTR, and visitor utility, not arbitrary quotas.

## Topic-cluster rules

Use durable hub pages under `/topics/<slug>` or the site's existing category scheme, while keeping existing `/blog/<slug>` URLs stable. Each hub must add genuine navigation and introductory value. Canonicalize duplicate keyword variants to the primary article rather than publishing near-duplicates. Avoid creating pages merely to fill topic quotas.

## Performance and quality gates

- 100% published posts visible on public blog, routable with status 200, listed once in XML sitemap, and internally linked.
- 0 unreviewed published finance articles, 0 false claims/placeholder sources, 0 broken download links.
- 0 article slug collisions or titles with indistinguishable search intent.
- Track GSC clicks, impressions, indexed vs discovered URLs, engagement, printable downloads, successful tool completions, and ad page RPM by template.
